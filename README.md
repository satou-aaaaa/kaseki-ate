# 化石あて（kaseki-ate）

化石になった生き物の説明（節足動物のなかま・イカやタコのなかま・汽水を好んだ貝 など）を読んで、示準化石（三葉虫・フズリナ・アンモナイト・恐竜・ビカリア）を当てる1日5問の学習ゲーム。正解したら「どの時代？」（古生代・中生代・新生代）も選ぶ。中学1年理科「大地の成り立ちと変化」。

遊ぶ: <https://satou-aaaaa.github.io/kaseki-ate/>

- 中身は大阪府教育委員会の中学1年理科プリント、群馬県立自然史博物館のワークシート、大阪府教育センターの標本紹介、沖縄県立博物館・美術館のワークシートで確かめたことだけです。
- 示相化石は今日のまめ知識で扱います。岩石は「岩石なかま分け」で扱います。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
